## 2. Nombre del proyecto

**presencIA** — *"Tu negocio en tiempos de IA"*.

Plataforma de auditoría y seguimiento de posicionamiento SEO y GEO (*Generative Engine Optimization*) para empresas.

## 3. Qué quiero hacer

Quiero crear un aplicación web que, introducida la URL de una página web, realiza una auditoría en tiempo real de su posicionamiento en buscadores convencionales (SEO) y en motores de IA generativa (GEO), junto con el análisis de preparación para respuestas (AEO), entregando un informe de puntuación.

El resultado se muestra en la aplicación o se exporta si el usuario rellena con su nombre y con su email un formulario (si fuese para una empresa real, esto se haría para poder hacer campañas de email marketing y para poder concertar una cita de venta con el usuario). 

La aplicación tendrá una zona privada, donde los usuarios registrados podrán ver un panel con las puntuaciones de su/s marca/s en tiempo real, una sección de keywords y un apartado para dejar consultas. En la sección privada se podrán descargar informes personalizados.

## 4. Qué problema o necesidad resuelve

Las empresas que poseen una web no tienen forma de saber si su presencia digital está preparada para la visibilidad en buscadores convencionales y, sobre todo, en los nuevos motores de respuesta generativa (GEO y AEO). Las herramientas SEO existentes dan prioridad al SEO clásico y no cubren esta capa.

`presencIA` audita de forma automática el SEO y la preparación para IA, y ofrece el servicio profesional de mejoras.

## 5. Para quién

La aplicación estaría dirigida al ámbito empresarial: empresas, de cualquier tamaño, o personas jurídicas propietarias de páginas web que quieran llevar un control sobre el posicionamiento de sus marcas en buscadores convencionales y en IA.
