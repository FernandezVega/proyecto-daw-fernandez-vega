# presencIA

Plataforma de auditoría y seguimiento de posicionamiento SEO y GEO (Generative Engine Optimization) para empresas. La aplicación estaría dirigida al ámbito empresarial: empresas, de cualquier tamaño, o personas jurídicas propietarias de páginas web que quieran llevar un control sobre el posicionamiento de sus marcas en buscadores convencionales y en IA.

**Estado:** en construcción. Proyecto del módulo Proyecto DAW (0616), curso 2026-27.

**Autoría:** Claudia Fernández Vega (FernandezVega).
